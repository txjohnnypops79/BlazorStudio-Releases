# Blazor Studio Roadmap

This roadmap outlines the planned direction of Blazor Studio. Priorities may change based on technical requirements, development progress, and community feedback.

## Phase 1 — Foundation and Public Preview

- [x] Initial public preview distribution
- [x] Windows MSI installer
- [x] Community Discord server
- [ ] Product documentation
- [ ] Public development demonstrations
- [ ] Application code signing
- [ ] Installer integrity verification
- [ ] Stability and compatibility improvements
- [ ] Automated build and release pipeline

## Phase 2 — Visual Designer

- [ ] Expand the visual component toolbox
- [ ] Improve drag-and-drop functionality
- [ ] Improve property editing
- [ ] Component hierarchy and navigation
- [ ] Undo and redo
- [ ] Copy, paste, and duplicate components
- [ ] Responsive layout controls
- [ ] Reusable component support
- [ ] Custom component registration
- [ ] Third-party component library integration

## Phase 3 — Developer Experience

- [ ] Improved Razor code generation
- [ ] C# code-behind integration
- [ ] Visual event configuration
- [ ] Data binding
- [ ] Live application preview
- [ ] Existing Blazor project integration
- [ ] Project templates
- [ ] Build and validation feedback
- [ ] Maintainable, developer-friendly generated code

## Phase 4 — Data and Application Integration

- [ ] Database connectivity
- [ ] Entity Framework Core integration
- [ ] REST API integration
- [ ] Visual data source configuration
- [ ] Forms and validation
- [ ] Data grids and reporting
- [ ] Authentication integration
- [ ] Dependency injection support

## Phase 5 — NuGet Package

The goal is to make the visual design engine reusable outside of the standalone Blazor Studio application.

- [ ] Separate the designer engine from the desktop application
- [ ] Define public integration interfaces
- [ ] Support custom component registration
- [ ] Provide extensibility hooks
- [ ] Create developer documentation
- [ ] Publish an initial NuGet preview package
- [ ] Provide integration examples

## Phase 6 — Visual Studio Extension

Bring the Blazor Studio design experience directly into Visual Studio.

- [ ] Investigate Visual Studio extensibility requirements
- [ ] Integrate the visual design surface
- [ ] Connect with existing Razor projects
- [ ] Synchronize visual changes with source code
- [ ] Integrate property editing and component navigation
- [ ] Publish an initial extension preview
- [ ] Evaluate Visual Studio Marketplace distribution

## Long-Term Vision

Blazor Studio aims to provide a flexible visual development ecosystem rather than locking developers into a single application or workflow.

The guiding principles are:

- Developer ownership of generated code.
- Standard .NET and Blazor technologies.
- Extensibility and interoperability.
- Reduced repetitive UI development.
- Clean and maintainable application architecture.

## Community Feedback

Suggestions and feature requests are welcome through GitHub Issues and the [Discord community](https://discord.gg/VGbJdApYM).

This roadmap is subject to change and does not represent a commitment to specific delivery dates.
