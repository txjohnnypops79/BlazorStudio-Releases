# Blazor Studio

**Build Visually. Code Freely.**

Blazor Studio is an independent development project focused on bringing a Windows Forms-style visual design experience to modern .NET Blazor development.

The goal is to simplify UI development while allowing developers to retain control over their C# and Razor code.

## Project Status

Blazor Studio is currently in early preview. The application is under active development and may contain bugs, limitations, and unfinished features.

The current preview is available at no cost for testing and community feedback.

## Project Vision

Blazor Studio aims to provide:

- Visual drag-and-drop page and component design.
- Component toolbox and property editing.
- C# and Razor code integration.
- Live application previews.
- Reusable and custom components.
- Event handling and data binding.
- Database and API integration.
- Support for standard Blazor projects.
- Integration with third-party component libraries.

These represent the overall project direction. Not all features are implemented in the current preview.

## Long-Term Goals

Blazor Studio is intended to evolve into three complementary development tools:

### Standalone Desktop Application

A dedicated visual development environment for designing and building Blazor applications.

### NuGet Package

A reusable visual design engine that developers can integrate into their own applications, development tools, and custom solutions.

### Visual Studio Extension

A visual designer integrated directly into Visual Studio, allowing developers to work with Razor components within their existing development environment.
