NORTHSTAR WORKSHOP

Open NorthstarWorkshop.csproj in Blazor Studio.
Expand Components > Pages and open Home.razor in Design.
Use the welcome PDF for guided edits and save your changes with Save all.

To run: select NorthstarWorkshop in Build settings, choose the http profile,
and click Build & Run. Use Preview or Open browser to view the website.

This fictional website has Overview, Services and Contact pages. It needs no
external fonts, database, authentication or third-party UI package. The Contact
email address is an example only; there is no message submission backend.

Shared appearance: wwwroot/app.css
Shared navigation: Components/MainLayout.razor
Page content: Components/Pages

Edit a copy. You can restore the example by extracting a fresh welcome ZIP.
