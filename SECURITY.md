# Security Policy

## Project Status

Blazor Studio is currently in early preview. Security, stability, and compatibility improvements are ongoing development priorities.

## Supported Versions

Security reports are currently accepted for the latest publicly available preview.

| Version | Security Reports Accepted |
|---|---|
| 1.0.1 Preview | Yes |

## Official Distribution

Blazor Studio preview installers are distributed through the official GitHub Releases repository:

https://github.com/txjohnnypops79/BlazorStudio-Releases/releases

Users should avoid downloading installers from unofficial mirrors or third-party sources.

## Installer Verification

Where available, SHA-256 checksums will be published alongside release information to allow users to verify installer integrity.

Code-signing improvements are planned as part of the project's release process.

## Reporting a Vulnerability

If you discover a potential security vulnerability:

1. Do not publish sensitive vulnerability details in a public GitHub issue.
2. Contact the project maintainer privately through the Discord community.
3. Include the affected version, reproduction steps, and relevant technical information.
4. Allow a reasonable opportunity for the issue to be investigated before public disclosure.

[Discord Community](https://discord.gg/VGbJdApYM)

## Responsible Disclosure

Good-faith security research and responsible vulnerability reporting are encouraged.

Researchers should avoid accessing, modifying, or disclosing data that does not belong to them.

## Preview Software

Preview releases should be evaluated in non-production environments. No guarantee of security, reliability, or suitability for production use is provided.

Thank you for helping improve the security of Blazor Studio.
